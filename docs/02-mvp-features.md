# MVP Features

## MVP Goal

Build a basic educational platform where:
- Tutors can upload educational resources
- Students can browse and learn freely

The MVP should validate:
- Student interest
- Tutor participation
- Content organization

---

# Core Features

## 1. Authentication

### Tutor Authentication
- Sign up
- Login
- Logout

### Student Authentication
- Optional during MVP
- Students may browse freely

---

## 2. Tutor Profiles

Tutors can:
- Add profile photo
- Add bio
- Add subjects
- Add syllabus types

---

## 3. Subject Categories

Examples:
- Local A/L
- Local O/L
- Edexcel
- Cambridge
- Grade 1–5
- Grade 6–9

---

## 4. Lesson Uploading

Tutors can:
- Add YouTube video links
- Upload PDF notes
- Add lesson title
- Add lesson description

---

## 5. Video Embedding

Videos should:
- Play inside the platform
- Be organized by lesson order

---

## 6. Material Downloading

Students can:
- Download PDF notes
- Access materials freely

---

## 7. Browsing System

Students can:
- Browse by subject
- Browse by syllabus
- Browse by tutor

---

# Features NOT Included in MVP

- Payments
- Messaging
- Live classes
- Ratings
- Reviews
- AI features
- Video hosting
- Notifications

These may be added in future versions.
